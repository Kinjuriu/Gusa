# Gusa
Gusa, meaning “touch” in Swahili, is a local-first Android accessibility assistant designed to make digital services more accessible to Kenyans with disabilities. It helps deafblind, blind, low-vision, deaf, and hard-of-hearing users understand and interact with mobile applications, websites, and online forms through Braille input, haptic feedback.
